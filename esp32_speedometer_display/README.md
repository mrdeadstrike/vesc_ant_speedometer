# ESP32 speedometer display

Прошивка четырёхразрядного индикатора для дублирования скорости с Raspberry Pi. ESP32 поднимает Bluetooth Classic/SPP-устройство с именем `SpeedDisplay` и получает от основного `speedometer.py` строки вида `SPEED 42`.

Формат индикатора:

- обычно скорость `0–99` показывается в двух центральных разрядах;
- при скорости `100–999` используются первые три разряда, а четвёртый остаётся пустым;
- таймер `0–60` работает скрыто; при достижении 60 км/ч его результат показывается пять раз миганием как `SS:CC`, где `SS` — секунды, `CC` — сотые секунды;
- затем индикатор возвращается к скорости; новая попытка сбрасывается, когда скорость станет нулевой.
- если после старта с нуля 60 км/ч не достигнуты за 20 секунд, замер отменяется без индикации; повторная попытка будет только после следующей остановки до `0`.
- пока Raspberry Pi подключается, Bluetooth разорван или пакеты скорости не приходят две секунды, по внешнему периметру разрядов бежит двухсекционный контур; цифры старой скорости не остаются на экране.
- пока по конкретному FarDriver не пришли свежие температура контроллера и температура мотора, в нижнем квадрате соответствующего крайнего разряда крутятся две секции: слева — передний (`slave`), справа — задний (`master`).

## Подключение

| Контакт индикатора | ESP32 |
| --- | --- |
| Питание `GND` | `GND` |
| Питание `VCC` | `5V` |
| `CLK` на одном из разъёмов | `GPIO27` |
| `DIO` на том же разъёме | `GPIO14` |

Это один четырёхразрядный TM1637-совместимый индикатор, а не два независимых двухразрядных. Два боковых разъёма дублируют один и тот же интерфейс `GND`, `VCC`, `DIO`, `CLK`: используйте только одну пару сигнальных линий. Внешние библиотеки не требуются.

Провода, которые сейчас идут на `GPIO26` и `GPIO25`, можно убрать с индикатора; скетч также переводит эти GPIO во входы, поэтому они не конфликтуют с рабочими `GPIO14/27` даже до отключения.

> Важно: GPIO ESP32 не рассчитаны на 5 В. Если на линиях `CLK`/`DIO` платы стоят подтяжки к 5 В, перед постоянным использованием добавьте двунаправленный преобразователь логических уровней 3.3 В ↔ 5 В. Питание индикатора от 5 В при общей земле допустимо, но не означает, что его сигнальные линии безопасны для ESP32.

## Загрузка и подключение к Raspberry Pi

1. В Arduino IDE откройте файл `esp32_speedometer_display/esp32_speedometer_display.ino`.
2. Выберите свою ESP32-плату и порт в меню **Tools**.
3. Нажмите **Upload**.
4. После прошивки ESP32 будет виден в Bluetooth как `SpeedDisplay`.
5. Включите Raspberry Pi и основной `speedometer.py`. Он сам найдёт устройство по имени и подключится по SPP/RFCOMM.

Обычно MAC указывать не нужно. Если в зоне несколько устройств с именем `SpeedDisplay`, задайте на Raspberry Pi перед запуском:

```bash
export SPEED_DISPLAY_BT_ADDRESS=AA:BB:CC:DD:EE:FF
./run.sh
```

При первом подключении BlueZ может попросить привязать устройство. Тогда на Raspberry Pi выполните один раз `bluetoothctl`, затем `scan on`, `pair <MAC>`, `trust <MAC>` и `quit`; далее поиск и подключение будут автоматическими.

## Если экран пустой

На фото не читаются подписи `CLK` и `DIO` рядом с разъёмами. Если после прошивки индикатор не реагирует, поменяйте местами пары в начале `.ino`:

```cpp
constexpr uint8_t RIGHT_CLK_PIN = 14;
constexpr uint8_t RIGHT_DIO_PIN = 27;
```

Это меняет только порядок сигнальных линий; питание трогать не нужно.
